# Exam-Readiness Pack — Claude Certified Architect: Foundations

This folder is study scaffolding for the **Claude Certified Architect – Foundations** exam. It maps
what AI-OS teaches onto the real exam, flags the gaps, and reconciles the project's own conventions
with actual Anthropic terminology so you don't memorize the wrong names.

> **Honest framing.** This project is a strong *conceptual* foundation and hands-on MCP practice, but
> it is **not, by itself, sufficient** to guarantee a pass. Treat it as one input alongside the
> official materials. See [coverage-map.md](coverage-map.md) for the blunt gap analysis.

## What's here
| File | Purpose |
|---|---|
| [blueprint.md](blueprint.md) | What the exam actually is — official facts vs. unverified third-party numbers, with sources. |
| [coverage-map.md](coverage-map.md) | Each AI-OS topic → exam domain, rated **Covered / Partial / Gap**, plus a readiness estimate. |
| [study-guide.md](study-guide.md) | Per-domain: what the project teaches, and what to study beyond it (with links). |
| [vendor-reconciliation.md](vendor-reconciliation.md) | The project's coined frameworks & abstractions vs. real Anthropic products/terms. |
| [agent-sdk-and-claude-code.md](agent-sdk-and-claude-code.md) | Reference for the **real** Claude Agent SDK, Managed Agents, MCP connector, Agent Skills, and Claude Code — the products the exam actually tests. |

## The one prerequisite reality
The exam is **gated to organizations in the Claude Partner Network** and delivered via Pearson VUE.
The **authoritative blueprint is a partner-gated Exam Guide PDF** — the numbers circulating on prep
sites (domain weights, question count, passing score) are third-party and **unverified**. If your org
(`ecanarys.com`) is in the partner network, get that PDF and the Partner Academy course; they
supersede everything here.

## How to use this pack
1. Read [blueprint.md](blueprint.md) to calibrate what's official vs. rumor.
2. Work [coverage-map.md](coverage-map.md) to see where AI-OS gets you and where it doesn't.
3. Use [study-guide.md](study-guide.md) as a checklist, filling gaps from Anthropic's docs.
4. Skim [vendor-reconciliation.md](vendor-reconciliation.md) before the exam so project-specific
   names (PRECISE/SPIDER/CALM) don't mislead you.
